# Skróty klawiszowe

Głównym modyfikatorem jest `Super`. Aktualną listę można zawsze otworzyć przez
`Super+F1`; menu jest generowane z aktywnej konfiguracji Hyprlanda.

## Aplikacje i system

| Skrót | Akcja |
| --- | --- |
| `Super+Enter` | Foot |
| `Super+Space` | Fuzzel |
| `Super+B` | Zen Twilight |
| `Super+E` | Thunar |
| `Super+M` | Plexamp |
| `Super+N` | Centrum powiadomień |
| `Super+L` | Blokada sesji |
| `Super+Escape` | Menu zasilania |
| `Super+Shift+E` | Alias menu zasilania |
| `Super+Shift+A` | EasyEffects |
| `Super+F1` | Lista skrótów |

## Okna

| Skrót | Akcja |
| --- | --- |
| `Super+Q` | Zamknij aktywne okno |
| `Super+C` | Alias zamykania |
| `Super+T` | Floating/tiling |
| `Super+F` | Maksymalizacja z panelami |
| `Super+Shift+F` | Pełny ekran bez paneli |
| `Super+P` | Pseudotile |
| `Super+S` | Zmień kierunek podziału dwindle |
| `Super+strzałki` | Przenieś fokus |
| `Super+Shift+strzałki` | Przenieś okno |
| `Super+lewy przycisk myszy` | Przeciągnij okno |
| `Super+prawy przycisk myszy` | Zmień rozmiar okna |

## Pulpity

| Skrót | Akcja |
| --- | --- |
| `Super+Tab` | Następny pulpit |
| `Super+Shift+Tab` | Poprzedni pulpit |
| `Super+1…0` | Pulpit 1–10 |
| `Super+Shift+1…0` | Przenieś okno na pulpit 1–10 |

## Schowek, głos i zrzuty ekranu

| Skrót | Akcja |
| --- | --- |
| `Super+Shift+V` | Historia schowka i automatyczne wklejenie |
| `Alt+Z` | Pokaż lub ukryj nakładkę GPU Screen Recorder |
| `Super+G` | Alternatywny skrót nakładki GSR |
| `Super+Shift+R` | Włącz lub wyłącz bufor replay |
| `Super+R` | Zapisz ostatnie 120 sekund |
| `Print` | Zaznacz obszar i otwórz edytor Satty |
| `Shift+Print` | Przechwyć aktywne okno i otwórz edytor Satty |
| `Ctrl+Print` | Zapisz cały ekran i skopiuj go do schowka |
| `Super+Shift+S` | Menu zrzutów: obszar, aktywne okno lub cały ekran |
| `Super+Ctrl+S` | Uruchom animowany wygaszacz `WOJTECH` |

## Klawisze multimedialne

- klawisze głośności zmieniają poziom o 5%,
- mute działa osobno dla wyjścia i mikrofonu,
- klawisze jasności zmieniają poziom o 5%,
- play/pause, next i previous sterują przez Playerctl.
