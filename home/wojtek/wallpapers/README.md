# Tapety Biscuit

Trzy tapety zostały wygenerowane jako zasoby projektu i są rotowane razem z
oryginalnym tłem Biscuit:

- `frieren-observatory.png` — melancholijne fantasy z obserwatorium, runami Git
  i ukrytym symbolem blokady;
- `night-ops.png` — oryginalna scena cyber-thrillera z terminalami, grafem
  zależności i motywem bezpieczeństwa;
- `devsecops-owl.png` — centrum operacyjne z sową, gumową kaczką, liczbą 42,
  grafem Git oraz symbolami Nix i bezpieczeństwa.

Obrazy wygenerowano w palecie Biscuit de Mar Dark za pomocą wbudowanego
generatora obrazów Codex. Kompozycje zostawiają spokojniejszą lewą stronę pod
okna terminala. Awww skaluje i przycina je do proporcji aktywnego monitora.
